# 医于垣笺 · yiyu-yuanjian

> **数据在垣内，建议仅作笺注。**

面向普通个人（零基础用户）的**离线医疗资料整理助手**配置包：让你自己电脑里的 AI 只阅读你导入的资料，帮你做整理、摘录和大白话解读，输出仅供参考，不做诊断。

## 名称释义

- **垣**：一道隔离的边界。指数据只在你的本机内处理，不出你的电脑。
- **笺**：辅助性质的批注、建议。指输出仅为参考，不是诊断结论。

## 这是什么 / 不是什么

**是什么：** 一套文档与预设配置，包含系统提示词、三份虚构练习资料、小白图文式操作说明。

**不是什么：**

- 本仓库**没有安装包（EXE）**，v0.1.0 不提供任何可执行程序；
- 本仓库**不包含、不分发任何 AI 模型文件**；
- 本项目不是医疗器械、不是医疗服务，**不做诊断、不开处方、不提供药物剂量**。

运行底座是使用者自行安装的 **AnythingLLM Desktop（MIT）**；模型由使用者自行选择并下载（例如 **Qwen 系列**）。详见 `THIRD_PARTY_NOTICES.md`。

## 使用三步

1. **装**：自行安装 AnythingLLM Desktop，并准备一个本地模型（操作见《小白使用指南》）；
2. **导**：新建工作区，导入你自己的资料，把系统提示词粘贴进工作区设置；
3. **问**：在本机提问。助手会先引用资料原文，再用大白话解释；资料里没有的内容，它会说"我不确定"。

详细步骤（每一步都写明"你会看到什么"）：[`docs/小白使用指南.md`](docs/小白使用指南.md)
遇到问题先看：[`docs/常见问题.md`](docs/常见问题.md)
