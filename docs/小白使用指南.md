# 小白使用指南

> **免责声明：** 本工具仅用于在本机整理、解读你自己的医疗资料，**不提供诊断、处方或药物剂量，不能替代医生面诊**；出现胸痛、呼吸困难等紧急情况请立即拨打 120 或前往急诊。完整声明见 [`../DISCLAIMER.md`](../DISCLAIMER.md)。

> 这份指南默认你**完全没有电脑技术基础**。每一步都写明"你会看到什么"，照着点就行。
> 文中涉及软件界面的按钮名称，可能随版本更新略有变化；如对不上，请看《TODO.md》中标注"待验证"的条目。

## 你最终会得到什么

在自己电脑上得到一个"只跟你自己的资料对话"的助手：

- 资料只在**你这台电脑**里处理，不上传；
- 它只帮你整理、解释资料，**不会给你看病、开药**。

需要准备的东西：

1. 一台 Windows 或 macOS 电脑；
2. AnythingLLM Desktop 软件（需要联网下载安装一次）；
3. 一个本地 AI 模型（例如 Qwen 系列，需要联网下载一次）；
4. 本仓库里的提示词文件和你自己的资料。

> 下载和安装阶段需要联网；全部装好之后，日常使用可以离线进行（具体取决于你的模型配置方式）。

---

## 第一步：安装 AnythingLLM Desktop

1. 打开浏览器，访问 AnythingLLM 官方仓库（地址见 `THIRD_PARTY_NOTICES.md`，**以官方页面实际地址为准**），在发布页（Releases）找到 Desktop 版本；
2. Windows 用户下载 `.exe` 安装包，macOS 用户下载对应系统的安装包；
3. 双击安装包，一路点"下一步 / 继续"完成安装。

**你会看到什么：** 安装完成后，桌面上出现 AnythingLLM 的图标；第一次打开时，会进入一个引导页面，让你选择"模型提供方（LLM Provider）"和"数据存放位置"。

4. 数据存放位置建议选默认，或者选一个你记得住的文件夹（**不要选系统盘的临时目录**）；
5. 模型提供方先不用慌，做完第二步再回来选。

---

## 第二步：准备一个本地模型（以 Qwen 系列为例）

本地模型有两种常见的准备方式，**任选其一**即可。具体下载地址与最新操作方式，以模型官方页面为准（见 `THIRD_PARTY_NOTICES.md`，本指南不写死链接）。

### 方式 A：通过本地模型运行工具（更适合新手）

1. 下载安装一个本地模型运行工具（常见的有 Ollama、LM Studio 等，可自行选择，具体支持情况以 AnythingLLM 官方文档为准，**待验证**）；
2. 在工具内搜索 `qwen`，选择一个体积适合你电脑的模型（数字越小越省内存、跑得越快，例如 7B / 8B 一档；配置低就选更小的量化版本）；
3. 点"下载 / Pull / Download"，等它下载完；
4. 保持这个工具在后台运行。

**你会看到什么：** 工具里模型状态显示"已下载 / Running"。

5. 回到 AnythingLLM 的设置页，模型提供方选择这个工具对应的选项（如 Ollama / LM Studio），模型名选你刚下载的那一个，保存。

### 方式 B：手动下载模型文件

1. 到模型官方仓库或其指定的模型托管页面，下载一个适合你电脑配置的模型文件（常见格式为 `.gguf`，体积通常几个 GB）；
2. 在 AnythingLLM 的模型提供方中选择支持本地模型文件的选项，按页面提示指向你下载的文件；
3. 具体支持哪些格式与放置位置，**以 AnythingLLM 官方文档为准（待验证）**。

> 不会选就用方式 A。电脑内存 16GB 以下的，优先选 7B/8B 或更小的模型。

---

## 第三步：新建一个工作区

1. 打开 AnythingLLM；
2. 在界面上找到"新建工作区 / New Workspace"按钮（通常在侧边栏，按钮名称以实际版本为准）；
3. 给工作区起个名字，例如"我的资料"，确认创建。

**你会看到什么：** 左边出现一个叫"我的资料"的新工作区，中间是一个空白的聊天窗口。

---

## 第四步：导入资料

1. 进入"我的资料"工作区，找到上传资料的入口（常见形态是回形针图标，或工作区设置里的"文档 / Documents"，以实际界面为准）；
2. 把你自己的资料文件拖进去，或点按钮选择文件（常见支持 PDF、Word、TXT、图片等，支持格式以实际版本为准）；
3. 等待软件处理完成（界面上一般会显示"处理中 / Processing"，处理完会变成完成状态）。

**练习：** 可以先用本仓库 `assets/sample_records/` 里的三份**虚构**示例试一遍，确认流程没问题，再换成自己的真实资料。

> 真实资料建议先自己拍照、扫描清楚；看不清的部分，助手也会看不清。

---

## 第五步：粘贴系统提示词

1. 用记事本或任何文本编辑器打开本仓库的 `assets/prompts/医疗助手系统提示词.md`；
2. 复制文件里【提示词正文】两条横线之间的全部文字（说明文字不要复制）；
3. 在 AnythingLLM 中打开工作区设置（常见为齿轮图标），找到"系统提示词 / System Prompt"输入框；
4. 把刚才复制的内容粘贴进去，保存。

**你会看到什么：** 设置页提示设置已保存。此后这个工作区里的回答都会遵守这些规矩。

---

## 第六步：开始提问

在聊天窗口直接打字提问，建议从整理类问题开始，例如：

- "帮我把这份资料整理成条目。"
- "这上面有哪些项目超出了它印的参考范围？只陈述，别下结论。"
- "把 3 月和 6 月两份化验单上的血红蛋白数值对比一下。"
- "这个词是什么意思？用大白话解释。"

**你会看到什么：** 助手会先写"资料原文：……"，引用你导入资料里的句子，再用口语解释。如果资料里没有答案，它会说"资料里没有提到，我不确定"。

---

## 第七步：如何清除数据

按你的需要选一种：

1. **只删掉某一份资料：** 进入工作区的"文档 / Documents"列表，找到对应文件，点删除；
2. **清空整个工作区的对话：** 在工作区设置或聊天窗口菜单中找"清除对话 / Clear Chat"一类的按钮（名称以实际版本为准）；
3. **连工作区一起删掉：** 在工作区列表中对"我的资料"选删除；
4. **把数据从电脑上彻底移除：** 找到安装时选择的数据存放文件夹，删除其中对应内容；如不再使用，也可以直接卸载 AnythingLLM 并删除该文件夹。

> 删除前请确认：这个软件里的数据没有别处备份，删了找不回来。

---

## 记住三句话

1. 它只看你喂给它的资料，资料里没有的它会说不知道；
2. 它只做整理和解释，**看病、开药的事一律问医生**；
3. 出现胸痛、呼吸困难等紧急情况，**立刻打 120 或去急诊**，别等它回复。
