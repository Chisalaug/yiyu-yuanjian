# 常见问题（FAQ）

## 一、关于"它是什么"

### 1. 医于垣笺是一个能直接安装的软件吗？
不是。本仓库里**没有安装包（EXE），也没有任何 AI 模型**。它提供的是：一套系统提示词、三份虚构练习资料和使用文档。真正运行的底座是你自行安装的 AnythingLLM Desktop，模型也由你自行下载（例如 Qwen 系列）。一键安装包目前只在路线图中，属于"规划中"。

### 2. 它能给我看病吗？
不能，这是硬性定位。它只做资料整理、名词解释、数值对比这类辅助工作，**不做诊断、不开处方、不提供药物剂量**。身体不舒服请去医院。

### 3. 名字里的"垣"和"笺"是什么意思？
- **垣**：一道隔离的边界，指数据只在你自己电脑这道"墙"里处理，不出电脑；
- **笺**：辅助性质的批注、建议，意思是输出仅供参考，不是诊断结论。
一句话：数据在垣内，建议仅作笺注。

## 二、关于安装与模型

### 4. 一定要联网吗？
安装软件和下载模型时需要联网。装好之后，如果你使用的是本地模型，日常提问可以离线进行；是否完全离线，取决于你在 AnythingLLM 里选择的模型提供方（选在线 API 就会联网，选本地模型就不依赖外网）。

### 5. 这个软件收费吗？
本仓库的文档和提示词免费（MIT 许可证）。AnythingLLM Desktop 与 Qwen 模型各自的收费 / 授权政策，以其官方说明为准。

### 6. 我的电脑配置不高，跑得动吗？
可以先试体积较小的模型（例如 7B/8B 一档或更小的量化版本），速度和效果会弱一些，但整理文字资料一般够用。内存太小会明显变慢，具体最低配置以模型工具和 AnythingLLM 的官方说明为准（待验证）。

### 7. 下载模型时一堆版本号、字母，选哪个？
新手建议通过模型运行工具（如 Ollama / LM Studio）自动下载，不用手动分辨文件。手动下载时，数字代表模型规模，量化标识（如 Q4）越小越省内存、精度略低。拿不准就选最小的先跑通流程。

### 8. 安装时界面和指南写的不一样怎么办？
软件会更新，按钮名称可能变化。对照界面上意思最接近的选项操作即可；本仓库已把需要核实的界面描述登记在 `TODO.md`（标注"待验证"）。

## 三、关于数据与隐私

### 9. 我的病历资料会被上传吗？
设计目标是不上传：资料只在本机由本地软件和本地模型处理。但前提是你确实配置的是本地模型、底座软件在本机运行。请不要在配置里选择任何在线 API，否则数据会走对方的服务器。

### 10. 可以把自己的病历传到这个代码仓库里备份吗？
**不可以，也强烈不建议。** 仓库自带的 `.gitignore` 已经默认拦截常见资料格式和 `private/` 等文件夹。真实病历请只保存在本机安全位置。

### 11. 助手问我要姓名、身份证号怎么办？
按照系统提示词的规矩，它**不应该**索要姓名、身份证号、手机号、住址等信息。如果它问了，说明提示词没有生效（检查是否粘贴到正确的工作区设置），请不要提供，并重新保存提示词。

### 12. 怎么彻底删掉导入的资料？
见《小白使用指南》"第七步：如何清除数据"。可以分别删除单份资料、清空对话、删除整个工作区，或删除数据文件夹后卸载软件。

## 四、关于使用效果

### 13. 助手回答和我资料上写的不一样？
AI 可能出错。先看它引用的"资料原文"是不是你资料里真的有这句话；如果它引用的内容资料里根本没有，属于错误输出，请以纸质 / 原件为准，并重新提问或重新处理该份资料。

### 14. 我问"该吃什么药、吃多少"，它为什么不回答？
这是提示词里刻意设定的规矩。用药剂量、停药换药属于处方行为，必须由医生或药师决定，它只会提示你携带资料咨询专业人员。

### 15. 资料里没有的内容，它是怎么回答的？
按规矩，它应当回答"资料里没有提到，我不确定"。如果它开始自由发挥，说明提示词未生效或模型未遵守，请检查工作区的系统提示词设置。

### 16. 可以导入检查的照片、截图吗？
取决于你安装的 AnythingLLM 版本是否支持图片识别（OCR / 多模态）。稳妥做法是：先用三份虚构示例里的文字资料跑通；图片类资料建议先确认软件支持，或自行把关键数字抄成文字再导入（支持情况待验证）。

### 17. 软件报错、卡住不动怎么办？
按顺序尝试：① 等待几分钟（首次处理资料较慢）；② 重启 AnythingLLM；③ 确认本地模型工具正在运行、模型已下载完成；④ 新建一个干净工作区重新导入。仍无法解决时，携带具体报错文字到 AnythingLLM 官方仓库查询，本仓库不提供第三方软件的技术支持。

## 五、关于安全与就医

### 18. 什么情况下不要用它、直接去医院？
出现胸痛、胸闷、明显心慌、呼吸困难、嘴唇发紫、晕倒、意识不清、突然剧烈头痛、口角歪斜、言语不清、一侧肢体无力、大量出血、持续加重的剧烈腹痛、严重过敏等情况，**立即拨打 120 或前往急诊**。

### 19. 示例资料里的人是真的吗？
全部是虚构的。`assets/sample_records/` 里的人名（已隐去）、数值、日期、经过均为练习编造，与任何真实个人无关。
